# 玩家视角

```wen
依赖 视口库
将 结果 变成 玩家视口(640, 360, "玩家视角")
```

操作：

- `W/A/S/D` 前后左右
- 鼠标左键捕获视角，移动鼠标转头
- `Space` 上升，`Shift` 下降
- `Esc` 退出

返回：

```text
结果["帧数"]
结果["平均帧率"]
结果["OpenGL"]
结果["位置"]
```

## 场景 API

第 4 个参数可以传方块列表：

```wen
将 场景 变成 [
    {"位置": [0, 1.0, -4], "大小": 1.0, "颜色": 13336656}
]
将 结果 变成 玩家视口(640, 360, "场景", 场景)
```

每个方块有 `位置`、`大小`、`颜色`。第 5 个参数为 `真` 时全屏；第 6 个参数可传 `.obj` 模型路径。

## 当前限制

- 可见帧率约 30–60 FPS，受窗口合成器限制，不是 240
- 阴影是投影阴影，不是阴影贴图
- 只有方块，没有 OBJ 模型加载和贴图
- 碰撞是方块 AABB，不处理斜坡
