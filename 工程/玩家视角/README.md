# 玩家视角

```wen
依赖 视口库
将 结果 变成 玩家视口(640, 360, "玩家视角")
```

操作：

- `W/A/S/D` 前后左右
- 先左键点击窗口获得焦点并捕获鼠标；移动鼠标转头；右键释放/重新捕获
- `Space` 上升，`Shift` 下降
- `Esc` 退出

返回：

```text
结果["帧数"]
结果["平均帧率"]
结果["显示帧率"]
结果["刷新率"]
结果["位置"]
```

## 移动物理
- 按真实帧间隔 `dt` 移动，不再写死 0.016
- 重力 9.8，`Space` 跳跃，落地高度 1.7
- 分轴 AABB 滑动碰撞，撞墙不会整个人卡死
## 场景 API

第 4 个参数可以传方块列表：

```wen
将 场景 变成 [
    {"位置": [0, 1.0, -4], "大小": 1.0, "颜色": 13336656}
]
将 结果 变成 玩家视口(640, 360, "场景", 场景)
```

每个方块有 `位置`、`大小`、`颜色`。第 5 个参数为 `真` 时全屏；第 6 个参数可传 `.obj` 模型路径。

## 当前限制

- 渲染与显示已分线程：标题显示「刷新 / 渲染 / 显示」\n- 本机刷新率 165Hz；实测渲染约 120 FPS、显示约 64 FPS，仍不是 240\n- 显示器物理上限 165Hz，可见 240 帧不可能
- 阴影是方向光阴影贴图 + 3×3 PCF 软阴影
- 只有方块，没有 OBJ 模型加载和贴图
- 碰撞是方块 AABB，不处理斜坡
