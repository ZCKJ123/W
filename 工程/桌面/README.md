# 文桌面

纯文语言自绘桌面，只把系统窗口当像素输出，不使用系统按钮/菜单/控件。

```powershell
.\wen.exe 工程\桌面\桌面.wen
```

- 左上角图标：终端 / 文件 / 光影 / 设置
- 鼠标点击图标或方向键切换
- 回车打开自绘窗口
- Esc 退出
- 窗口标题栏、边框、阴影、任务栏、图标、任务栏时钟全部由 `界面` API 画
四个图标分别打开终端/文件/光影/设置页面，窗口尺寸随 `界面尺寸()` 调整。
