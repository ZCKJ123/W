# 文时钟 0.2-snapshot

文语言自绘的时钟界面，用来验证时间参照和秒针/分针/时针。

启动：

```powershell
.\wen.exe .\工程\时钟\时钟.wen
```

时间来源：

- `时间分量()`：年、月、日、时、分、秒、毫秒、星期、年日
- `时间戳()`：Unix 秒
- `高精度时间()`：单调时钟秒，适合算帧间隔
- `帧同步(60)`：按 60 FPS 限速，返回本帧实际耗时

绘图只用了：

```text
界面清屏 / 界面矩形 / 界面线 / 界面文本 / 界面刷新 / 界面事件
```

秒针按 `秒 + 毫秒/1000` 平滑走，不是每秒跳一下。

当前没有圆形填充，钟面外圈用 60 根刻度线表示；这是快照版的绘图能力边界。
