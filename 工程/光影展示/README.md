# 光影展示 / 漫游

双击项目根目录：

```text
启动光影漫游.bat
```

或桌面快捷方式 `文语言-光影漫游.lnk`（仅本机可选，不作为通用路径）。

它启动的是可漫游的 `工程\玩家视角\光影漫游.wen`，不是静态图。

操作：

- `W/A/S/D` 前后左右
- 鼠标移动转头（先左键点击窗口捕获鼠标，再移动转头）
- 右键释放/重新捕获鼠标
- `Space` 上升，`Shift` 下降
- `Esc` 退出

## 静态 PBR 图

单独看高采样 PBR 图：

```powershell
.\wen.exe 工程\光影展示\光影展示.wen
```

会保存 `例子\光影展示.bmp` 并打开静态视口。

## 材质

`材质预设("金" / "银" / "铜" / "玻璃" / "水" / "陶瓷" / "橡胶" / "自发光")`

PBR 参数：

| 字段 | 范围 |
|---|---|
| `粗糙度` | 0..1 |
| `金属度` | 0..1 |
| `折射率` | 1..3 |
| `纹理` | 无/棋盘/条纹/噪波 |
| `自发光` | 0..20 |
| `清漆` | 0..1 |
| `透射` | 0..1 |

`材质检查(材质)` 逐项校验范围。

## 注意

- 漫游窗口是 CPU 软件 3D，刷新 165Hz，渲染约 60–120 FPS，显示约 60 FPS
- 静态 PBR 图 640×360、4 采样，有噪点
- 帧率按本机 165Hz 刷新率，不再追 240
- 漫游场景是实时软件 3D：方块 + 球体、方向光阴影贴图 + PCF、SSAO，不是路径追踪 PBR
- 静态 PBR 图见 `PBR画廊.wen`
