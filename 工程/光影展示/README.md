# 光影展示

双击桌面：

```text
C:\Users\Acer\Desktop\文语言-光影展示.lnk
```

或双击：

```text
C:\Users\Acer\Desktop\zhongwen_lang\启动光影展示.bat
```

它会：

1. 用 PBR 材质渲染 640×360 路径追踪图
2. 保存 `例子\光影展示.bmp`
3. 打开静态视口窗口

## PBR 材质

```wen
将 材质 变成 [
    {"粗糙度": 0.16, "金属度": 1.0, "颜色": 5222496},
    {"粗糙度": 0.04, "金属度": 0.0, "折射率": 1.7, "颜色": 16777215},
    {"粗糙度": 0.08, "金属度": 0.0, "折射率": 1.33, "颜色": 4210752}
]
将 图 变成 光追渲染(640, 360, 8, 1.2, 1.0, 材质)
```

字段：

| 字段 | 范围 | 说明 |
|---|---|---|
| `粗糙度` | 0..1 | 金属/水面的模糊程度 |
| `金属度` | 0..1 | 大于 0.5 走金属反射 |
| `折射率` | 1..3 | 玻璃/水 |
| `颜色` | `0xRRGGBB` 十进制 | 基础色 |

`材质检查(材质)` 会逐项检查范围，返回标准化后的列表；越界直接报运行时错误。

## 注意

- 这是路径追踪，8 采样仍然有噪点
- 当前是 CPU 渲染，640×360 一张图约数秒
- 不是实时 240 帧
