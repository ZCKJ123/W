# 字节码 VM 计划（0.4 主攻方向）

## 为什么要做

现在解释器是 AST 走树，一条语句约 200 ns、一次函数调用约 0.6 µs。
已经做过的优化（返回不抛异常、帧内小数组、公式字典编译、纯表达式字节码）把
「体按公式」从 53.6 s 压到 196 ms，但**普通脚本循环**仍停在 200 ns/语句。

两次「绕过通用路径」的快速路径尝试（赋值快路径）都被对拍用例抓住语义偏差并回退，
说明问题不在某个分支慢，而在**语义分散在执行器的各个分支里**。

## 目标

| 指标 | 现在 | 目标 |
|---|---|---|
| 语句执行 | ~200 ns | ~20 ns |
| 函数调用 | ~0.6 µs | ~0.1 µs |
| 启动 | ~30 ms | < 10 ms（配合内建按需注册） |

## 最小指令集（第一步只做这些）

```
载常数 k            PUSH_K k
载全局槽 s          PUSH_G s
载局部槽 s          PUSH_L s
存全局槽 s          STORE_G s
存局部槽 s          STORE_L s
四则               ADD SUB MUL DIV MOD
比较               LT LE GT GE EQ NE
逻辑               AND OR NOT
跳转               JMP pc / JZ pc / JNZ pc
调用               CALL argc / RET
返回               RET
```

语义在**编译期**一次定死：局部还是全局、是否遮蔽、`返回` 走哪条路。
运行时只有一个 `switch (op)` 的取指-执行循环，不再有「运行时猜路径」。

## 已经落地的（提交 1605f9c）

| 项 | 结果 |
|---|---|
| 顶层 `当` 循环 200 万次 | 1116 ms → **234 ms**（约 4.8×） |
| 函数调用 20 万次 | 302 ms → **156 ms**（约 1.9×） |
| `斐(24)` | 95 ms → **49 ms**（约 1.9×） |
| `对于 … 在 范围(…) 中` 100 万次 | 418 ms | **56 ms**（约 7.5×） |
| 函数调用 20 万次 | 278 ms | **110 ms**（约 2.5×） |
| `斐(24)` | 70 ms | **35 ms**（约 2.0×） |
| 门禁 | 主用例 185/185、错误 15/15 全绿 |

> 上表的「之前」是同一个 wen.exe 加 `--无字节码` 的实测值，不是估的。

`对于` 还有一条独立的收益：`对于 序 在 范围(0, 1000000) 中` 以前会先造出一张
一百万元素的表（约 200 MB），现在整数步长直接按范围迭代，**连表都不造**。
小数步长仍然走造表路径——按表逐项相加和按范围累加会差最后一位，不能混。

关键实现（都在 `wen.cpp`）：

- 指令集：`BC_K/G/L/LC/STG/STL/STLL/ADD…MOD/LT…NE/NEG/NOT/JMP/JZ/RET/RETN/LINE/CALL`
- 编译器 `WenAsm`：语句 + 表达式的单遍递归下降；`且/或`（短路）、`对于`、`打印`、
  `尝试`、`匹配`、列表/字典一律编译失败 → 整块退回 AST
- 执行器 `Interpreter::runCode`：一条取指—执行循环，表达式栈按「深度指针」复用
  （`gVStack` + `gVSP`），嵌套调用只往上叠、不重新分配
- **语义只写一遍**：赋值抽成 `assignVarSym`、一元负号抽成 `negateValue`，
  AST 和 VM 共用；其余指令直接调 `applyBinary` / `valueEquals` / `truthy`
- `--无字节码` 开关：强制走 AST，供对拍（`测试/用例/130字节码对拍` 的期望值就是它生成的）

另有一条不属于字节码的收益：**函数帧池**。每次调用 `make_shared` 一个作用域太亏，
现在帧在「`use_count()==1` 也就是没有别处引用」时回收复用（闭包捕获过的帧绝不进池），
`svars` 的容量也跟着留着。光这一项就让 `斐(24)` 从 70 ms 掉到 35 ms。

## 已踩过的坑（别再犯）

1. **快路径绕过语义**：`将 x 变成 x+1` 的快路径漏了全局快槽与作用域的写入顺序 → 回退。
2. **零参数函数读 `paramSyms[0]`**：越界，直接 0xC0000005。判定前必须检查参数个数。
3. **哨兵值精度**：EDT 用 `1e18` 当哨兵会在 `f+q²` 时丢精度 → 已改 `1e7`（float）并写注释。
4. **角点索引顺序**：`(层,行,列)` 与 `(列,行,层)` 写反 → 4 个用例同时报错；改热点循环时先对照原实现。
