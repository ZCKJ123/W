# 文光追 0.2-snapshot

CPU 光追渲染，不依赖 GPU。渲染器是 C++ 内置 `光追渲染`；文语言负责场景调用、保存和界面。

```powershell
.\wen.exe 工程\光追\光追.wen
```

输出：

```text
例子\光追.bmp
```

路径追踪：每像素多次采样、多次弹射、面积光软阴影。场景：

- 3 个球
- 棋盘地面
- 点光源
- 阴影射线
- 天空渐变
- 多线程按行渲染

实测（本机，排除进程启动）：

| 分辨率 / 采样 | 64 位 FPS | 说明 |
|---|---:|---|
| 160 × 90 / 1 | 约 500 | 165 FPS 门禁用这一档 |
| 320 × 180 / 1 | 约 130 | 预览 |
| 320 × 180 / 4 | 约 35 | 可用画质 |
| 640 × 360 / 1 | 约 33 | 低采样 |
| 640 × 360 / 4 | 约 9 | 质量档 |

真正的路径追踪在 640×360 原生分辨率达不到 165 FPS。实时档用 5 号参数缩放内部渲染分辨率，再最近邻放大到 640×360：

| 输出 / 内部 | 采样 | 64 位 | 32 位 |
|---|---:|---:|---:|
| 640×360 / 115×64 | 1 | 约 246 | — |
| 640×360 / 51×28 | 1 | — | 约 252 |

这是低内部分辨率的路径追踪 + 降噪 + 双线性放大，不是把光栅冒充光追；内部仍有噪点，32 位内部只有 51×28，放大后偏糊。

## 动态光影

`动态光影.wen` 生成 24 帧，光源绕场景移动，阴影和水面随时间变化：

```powershell
.\wen.exe 工程\光追\动态光影.wen
```

时间参数是 `光追渲染(宽, 高, 采样, 时间, 内部缩放)` 的第 4 个参数。

## 本机复测（2026-11-17）

复跑命令：

```powershell
.\工具\光追基准.ps1
```

| 档位 | 帧/秒 | 单帧 |
|---|---:|---:|
| 640×360 原生 / 采样 1 | 44.0 | 22.7 ms |
| 640×360 内部 0.25 / 采样 1 | 379–401 | 2.49 ms |
| 640×360 内部 0.32 / 采样 1 | 290–306 | 3.27 ms |
| 640×360 内部 0.32 / 采样 2（新默认） | 175–189 | 5.29 ms |

逐像素用 `视口画点` 自绘 640×360 一帧要 139.2 ms，不能替代 `光追渲染`。
帧率随机器与降频浮动，上表是这台机器今天的值；完整说明见 `性能基准.md`。


内部缩放取多少：渲染内核提速后，0.32（205×115）配采样 2 是 175–189 帧、仍有 12%–25% 余量；
0.34 配采样 2 只剩 0–2%，采样 3 直接掉到 145 帧不达标。实时档默认建议 0.32 + 采样 2，
更省用 0.28 + 采样 2（224–241 帧）。
扫描命令：`.\工具\光追基准.ps1 -扫描`。
