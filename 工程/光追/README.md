# 文光追 0.2-snapshot

CPU 光追渲染，不依赖 GPU。渲染器是 C++ 内置 `光追渲染`；文语言负责场景调用、保存和界面。

```powershell
.\wen.exe 工程\光追\光追.wen
```

输出：

```text
例子\光追.bmp
```

路径追踪：每像素多次采样、多次弹射、面积光软阴影。场景：

- 3 个球
- 棋盘地面
- 点光源
- 阴影射线
- 天空渐变
- 多线程按行渲染

实测（本机，排除进程启动）：

| 分辨率 / 采样 | 64 位 FPS | 说明 |
|---|---:|---|
| 160 × 90 / 1 | 约 500 | 240 FPS 门禁用这一档 |
| 320 × 180 / 1 | 约 130 | 预览 |
| 320 × 180 / 4 | 约 35 | 可用画质 |
| 640 × 360 / 1 | 约 33 | 低采样 |
| 640 × 360 / 4 | 约 9 | 质量档 |

真正的路径追踪在 640×360 原生分辨率达不到 240 FPS。实时档用 5 号参数缩放内部渲染分辨率，再最近邻放大到 640×360：

| 输出 / 内部 | 采样 | 64 位 | 32 位 |
|---|---:|---:|---:|
| 640×360 / 160×90 | 1 | 约 373 | — |
| 640×360 / 96×54 | 1 | — | 约 311 |

这是低内部分辨率的路径追踪，不是把光栅冒充光追；内部画面仍有噪点、放大后偏糊。
