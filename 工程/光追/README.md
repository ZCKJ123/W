# 文光追 0.2-snapshot

CPU 光追渲染，不依赖 GPU。

```powershell
.\wen.exe 工程\光追\光追.wen
```

输出：

```text
例子\光追.bmp
```

场景：

- 3 个球
- 棋盘地面
- 点光源
- 阴影射线
- 天空渐变
- 多线程按行渲染

实测（本机，20 帧循环，排除进程启动）：

| 分辨率 | 每帧 | 折算 |
|---|---:|---:|
| 320 × 180 | 0.0015s | 666 FPS |
| 640 × 360 | 0.0041s | 244 FPS |

640×360 已过 240 FPS（反射 + 水面波纹版本约 244 FPS；32 位约 85 FPS）。当前是直接光 + 阴影，不是多次反射/折射/景深；要全套光追效果需要再加递归路径和采样。
