# 程序化 3D

圆环不是在 C++ 里写死的，是在 `文` 里用循环和三角网格生成的。

```wen
依赖 三维库, 视口库, 数学库
将 网 变成 网格新建()
...
网格三角(网, p00, p10, p11, 色, 0.6, 0.25)
...
将 场景 变成 [网]
玩家视口(640, 360, "程序化圆环", 场景, 假)
```

运行：

```powershell
.\wen.exe 工程\三维\程序化.wen
```

圆环：

- 28 段 × 12 环
- 672 个三角形
- 每个三角形有颜色、金属度、粗糙度
- `网格平移/缩放/旋转/合并` 可在 Wen 里改网格
- 交给玩家视口后走阴影贴图 + PCF + SSAO

窗口启动后先左键点击，再 `W/A/S/D` 或方向键移动；鼠标转头，右键释放，Esc 退出。
