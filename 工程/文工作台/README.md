# 文工作台 0.2（快照）

界面由文语言自己绘制，不再用 C++ 编辑框套壳。

- 文字、行、面板：`界面文本` / `界面线` / `界面矩形`
- 键盘字符、退格、方向键、Esc、Ctrl+S：`界面事件`
- 画面刷新：`界面刷新`
- 文语言维护文本、行、光标状态

启动：

```powershell
.\wen.exe .\工程\文工作台\工作台.wen
```

操作：

- 直接输入字符
- 退格删除
- Ctrl+S 保存为 `工作台草稿.wen`
- Esc 关闭

当前是快照版，绘图仍是 CPU 像素 + Win32 文本输出，不是硬件加速；滚动、选区、语法高亮还没做。
