# 文工作台 0.2

一个用文语言启动的 Windows 工作台：

- 上面是文代码编辑框
- 「保存草稿」写 `工作台草稿.wen`
- 「运行」保存后启动 `wen.exe` 执行草稿
- 关闭窗口后返回文语言，脚本继续执行

启动：

```powershell
.\wen.exe .\工程\文工作台\工作台.wen
```

入口代码：

```wen
将 草稿 变成 "打印 \"你好，文工作台\""
工作台("文工作台 0.2", 草稿)
```

界面外壳目前由 C++ 的 Win32 控件承载；文语言负责启动、初始内容和后续流程。
下一步要做“完全用文语言画控件”的版本，需要先补视口键盘/鼠标事件和非阻塞刷新。
