## 五条公理

1. **词法只认字符**：行首、行尾、前后文不影响切词；指令必须有显式边界。
2. **值位置只有值**：名字出现在值位置就取值，绝不偷偷调用；调用必须显式。
3. **一处定义**：关键字、算子、文法各只有一份来源，文档和测试从它生成。
4. **错误分四层**：词法、语法、静态、运行各报各的，不越界。
5. **组合性**：子表达式的意思不因外层而变。

违反其中一条，只有两条路：

- 放弃这个概念
- 明着改公理、升版本、写迁移

不允许在解析器里加一个兼容 `if`。

## 0.2 相对 0.1 的改动

### 1. 删除零参自动调用

0.1：

```wen
函数 报时 则
    返回 "十二点"
结束

打印 报时
```

`报时` 在值位置被自动调用。

0.2：

```wen
函数 报时 则
    返回 "十二点"
结束

打印 报时()      # 显式调用
将 函 变成 报时  # 取函数值
打印 函()        # 再显式调用
```

规则：

- `函数名` 在值位置永远表示函数值
- 调用必须写 `()`
- 零参函数不再有特殊求值路径

### 2. `√`、`°`、`²` 改核心 AST 节点

0.1：

- `√x` 生成对 `平方根` 的调用
- `x°` 生成对 `角度转弧度` 的调用
- `x²` 生成对 `**` 的调用

问题：`√16` 不写 `依赖 数学库` 会报“属于数学库”，因为它是偷偷调用库函数。

0.2：

| 写法 | AST 节点 | 语义 |
|---|---|---|
| `√x` | `根号节点` | 数值平方根 |
| `x°` | `角度节点` | 角度转弧度 |
| `x²` | `幂节点(x, 2)` | 平方 |
| `x³` | `幂节点(x, 3)` | 立方 |

规则：

- 不再依赖 `数学库`
- 不生成函数调用
- 非数字输入报运行时类型错误
- 优先级固定在“后缀”层

### 3. 保留并置调用，但钉死规则

并置调用是语言身份的一部分，不删。

产生式：

```ebnf
并置调用 = 标识符, 后缀表达式 ;
```

规则：

1. 并置调用只允许“标识符 + 一个后缀表达式”。
2. 并置调用与调用、索引同属最高优先级。
3. **并置调用不能直接和二元运算符混写**；混写必须加括号。

合法：

```wen
打印 加一 2              # 语句参数，单独一个并置调用
打印 正弦 30°            # 30° 是后缀表达式
打印 (加一 2) * 3        # 显式分组
打印 加一(2 * 3)         # 显式调用
```

非法：

```wen
打印 加一 2 * 3          # 语法错误：并置调用和 * 混写
打印 1 + 加一 2          # 语法错误
打印 2 ** 加一 3          # 语法错误
```

错误消息：

```text
并置调用不能直接和二元运算符混写；请用括号分组
```

注意：

- 这不会把 `加一 2 * 3` 解释成 9
- 也不会解释成 7
- 它根本没有值，语法层拒绝

### 4. 优先级定稿

从低到高：

```text
或
且
非
比较
+ -
* / // %
一元正负
**
调用 / 索引 / 并置调用
```

固定结论：

- `-2 ** 2` = `-(2 ** 2)` = `-4`
- `2 ** 3 ** 2` 右结合，等于 `2 ** (3 ** 2)` = `512`
- 并置调用在最高层，但不能和二元运算符直接混写

### 6. 错误分层

| 层 | 负责 | 例子 |
|---|---|---|
| 词法 | 字符、引号、数字、后缀拆词 | 文本没闭合、非法字符 |
| 语法 | 产生式、块闭合、并置混写 | 缺 `结束`、`加一 2 * 3` |
| 静态 | 名字、调用形态、参数个数 | 未知名字、调用非函数、参数数不对 |
| 运行 | 类型、除零、越界、资源 | 除数 0、下标越界、递归过深 |

错误消息必须带层名，不允许词法错误报成运行时错误。

## 迁移示例

| 0.1 | 0.2 |
|---|---|
| `打印 报时` | `打印 报时()` |
| `将 函 变成 报时` 后 `打印 函` | `打印 函()` |
| `√16` 且 `依赖 数学库` | `√16`，不再需要数学库 |
| `正弦 30°` | `正弦 30°`，`°` 不依赖数学库；`正弦` 仍需数学库 |
| `加一 2 * 3` | `(加一 2) * 3` 或 `加一(2 * 3)` |
| `绝对值 -5` | `绝对值(-5)` |

## 验收

1. `打印 报时` 输出函数值，不自动调用
2. `打印 报时()` 输出 `十二点`
3. 不写 `依赖 数学库`，`打印 √16` 输出 `4`
4. `打印 正弦 30°` 仍需 `依赖 数学库`，但 `°` 本身不再报数学库缺失
5. `打印 加一 2 * 3` 报语法错误，消息含“并置调用”
6. `打印 (加一 2) * 3` 输出 `9`
7. `打印 加一(2 * 3)` 输出 `7`
8. 文法和关键字表只有一份来源
