# 文语言 0.2 语法公理

状态：`0.2.0-snapshot` 已实施，不是正式版；1.0 才收正式版。核心边界、零参调用、并置硬规则、文本插值、`√`/`°`/`圆周率` 已按本文实施。  
仍留在纸上的：部分迁移项与未覆盖的旧写法。

## 库模型校正

33 个库不是外部模块，全部编译在同一个 `wen.exe` 里，是一张函数表。  
`依赖 数学库` 只做一件事：把数学库的名字放行到全局。

所以：

- 不存在“库跑起来了”
- 只有“这个名字现在能找到了”
- 库不启动、不加载、不隔离进程

真正的问题是：**语法符号被翻译成了库函数名**。

- `√16` → `平方根(16)`，属于数学库
- `30°` → `角度转弧度(30)`，属于数学库
- `"{x}"` → `文本(x)`，属于核心

前两个让同一行 `打印 √16` 因为文件头有没有 `依赖 数学库` 从合法运算变成运行时错误。  
语法符号不该有依赖。

因此 0.2 增加一条硬边界：**符号和常量的含义必须在核心，库只提供函数。**


## 五条公理

1. **词法只认字符**：行首、行尾、前后文不影响切词；指令必须有显式边界。
2. **值位置只有值**：名字出现在值位置就取值，绝不偷偷调用；调用必须显式。
3. **一处定义**：关键字、算子、文法各只有一份来源，文档和测试从它生成。
4. **错误分四层**：词法、语法、静态、运行各报各的，不越界。
5. **组合性**：子表达式的意思不因外层而变。

违反其中一条，只有两条路：

- 放弃这个概念
- 明着改公理、升版本、写迁移

不允许在解析器里加一个兼容 `if`。

## 0.2 相对 0.1 的改动

### 1. 删除零参自动调用

0.1：

```wen
函数 报时 则
    返回 "十二点"
结束

打印 报时
```

`报时` 在值位置被自动调用。

0.2：

```wen
函数 报时 则
    返回 "十二点"
结束

打印 报时()      # 显式调用
将 函 变成 报时  # 取函数值
打印 函()        # 再显式调用
```

规则：

- `函数名` 在值位置永远表示函数值
- 调用必须写 `()`
- 零参函数不再有特殊求值路径

### 2. `√`、`°`、`²` 改核心 AST 节点

0.1：

- `√x` 生成对 `平方根` 的调用
- `x°` 生成对 `角度转弧度` 的调用
- `x²` 生成对 `**` 的调用

问题：`√16` 不写 `依赖 数学库` 会报“属于数学库”，因为它是偷偷调用库函数。

0.2：

| 写法 | AST 节点 | 语义 |
|---|---|---|
| `√x` | `根号节点` | 数值平方根 |
| `x°` | `角度节点` | 角度转弧度 |
| `x²` | `幂节点(x, 2)` | 平方 |
| `x³` | `幂节点(x, 3)` | 立方 |
| `"{x}"` | `插值节点(x)` | 核心格式化，不调用 `文本(x)` |

规则：

- 不再依赖 `数学库`
- 不生成函数调用
- 非数字输入报运行时类型错误
- 优先级固定在“后缀”层

### 3. 保留并置调用，但钉死规则

并置调用是语言身份的一部分，不删。

产生式：

```ebnf
并置调用 = 标识符, 后缀表达式 ;
```

规则：

1. 并置调用只允许“标识符 + 一个后缀表达式”。
2. 并置调用与调用、索引同属最高优先级。
3. **并置调用不能直接和二元运算符混写**；混写必须加括号。

合法：

```wen
打印 加一 2              # 语句参数，单独一个并置调用
打印 正弦 30°            # 30° 是后缀表达式
打印 (加一 2) * 3        # 显式分组
打印 加一(2 * 3)         # 显式调用
```

非法：

```wen
打印 加一 2 * 3          # 语法错误：并置调用和 * 混写
打印 1 + 加一 2          # 语法错误
打印 2 ** 加一 3          # 语法错误
```

错误消息：

```text
并置调用不能直接和二元运算符混写；请用括号分组
```

注意：

- 这不会把 `加一 2 * 3` 解释成 9
- 也不会解释成 7
- 它根本没有值，语法层拒绝

### 4. 优先级定稿

从低到高：

```text
或
且
非
比较
+ -
* / // %
一元正负
**
调用 / 索引 / 并置调用
```

固定结论：

- `-2 ** 2` = `-(2 ** 2)` = `-4`
- `2 ** 3 ** 2` 右结合，等于 `2 ** (3 ** 2)` = `512`
- 并置调用在最高层，但不能和二元运算符直接混写

### 5. 一处定义

0.2 的“一处定义”现状：

- 文法唯一来源：根目录 [`../语法.ebnf`](../语法.ebnf)
- 关键字表、算子表是**参考快照**，不是解析器运行时来源
- 解析器仍用 C++ 硬编码关键字；表只用于审阅和对照

`语法总表.md`、`使用教程.md` 里的计数和优先级由工具生成，不手抄。

### 6. 错误分层

| 层 | 负责 | 例子 |
|---|---|---|
| 词法 | 字符、引号、数字、后缀拆词 | 文本没闭合、非法字符 |
| 语法 | 产生式、块闭合、并置混写 | 缺 `结束`、`加一 2 * 3` |
| 静态 | 名字、调用形态、参数个数 | 未知名字、调用非函数、参数数不对 |
| 运行 | 类型、除零、越界、资源 | 除数 0、下标越界、递归过深 |

错误消息必须带层名，不允许词法错误报成运行时错误。

## 核心边界

核心不是“解释器里现在碰巧能跑的东西”，而是：

> **不写任何 `依赖` 也能成立的语义集合。**

按这条，0.1 不及格。

### 现状实测

不写任何 `依赖`，能跑的核心函数只有 15 项左右：

```text
排序、反转、新建集合、键、值、有键、查找、替换、分割、修剪、
格式化、长度、类型、文本、范围
```

不能跑的数学库函数 8 项：

```text
平方根、绝对值、取整、正弦、圆周率、阶乘、平均数、求和
```

切分是随意的：

- 排序、反转在核心，求和、平均数在数学库
- 新建集合在核心，集合添加、交集、并集在集合库
- 圆周率是常量，却要依赖数学库

### 0.2 定界规则

1. **符号属于核心**：`√`、`°`、`²`、`³`、文本插值，必须是 AST 节点，永远不生成库函数调用。
2. **常量属于核心**：`圆周率`、`自然常数` 是字面常量，不需要依赖。
3. **基础容器操作属于核心**：构造、长度、索引、添加、删除、存在、键、值。
4. **聚合操作不许一半一半**：`求和`、`平均数`、`中位数`、`最大`、`最小` 全部归核心；要么全核心，要么全库，不能按拍脑袋分。
5. **库只提供函数**：库可以提供 `正弦`、`阶乘`、`集合交集` 这类函数，但不能提供符号的含义。
6. **高级代数留在库**：集合的交、并、差、子集、对称差留在集合库；它们不是语法符号。

### 核心 / 库边界表（提案）

| 项目 | 0.2 归属 | 理由 |
|---|---|---|
| `√` `°` `²` `³` | 核心 AST | 语法符号 |
| 文本插值 | 核心 AST | 语法符号 |
| `圆周率` `自然常数` | 核心常量 | 常量不是函数 |
| `求和` `平均数` `中位数` `最大` `最小` | 核心 | 基础聚合，和排序/反转同类 |
| `排序` `反转` | 核心 | 基础容器操作 |
| `长度` `类型` `文本` `范围` | 核心 | 基础语义 |
| 集合构造/添加/删除/存在/长度 | 核心 | 基础容器操作 |
| 集合交/并/差/子集/对称差 | 集合库 | 高级代数 |
| `平方根` `绝对值` `取整` | 数学库 | 函数；符号 `√` 已在核心 |
| `正弦` `余弦` `对数` | 数学库 | 数学函数 |
| `阶乘` | 数学库 | 数学函数 |
| `随机` `排列` `组合` | 数学库 | 数学函数 |

### 验收

1. 不写任何 `依赖`，`打印 √16` 输出 `4`
2. 不写任何 `依赖`，`打印 圆周率` 输出 `3.14159...`
3. 不写任何 `依赖`，`打印 求和([1, 2, 3])` 输出 `6`
4. 不写任何 `依赖`，`打印 平均数([1, 2, 3])` 输出 `2`
5. `集合添加` 不依赖集合库；`交集` 仍依赖集合库
6. 库函数不能改变 `√`、`°`、`²`、插值的含义

## 迁移示例

| 0.1 | 0.2 |
|---|---|
| `打印 报时` | `打印 报时()` |
| `将 函 变成 报时` 后 `打印 函` | `打印 函()` |
| `√16` 且 `依赖 数学库` | `√16`，不再需要数学库 |
| `正弦 30°` | `正弦 30°`，`°` 不依赖数学库；`正弦` 仍需数学库 |
| `加一 2 * 3` | `(加一 2) * 3` 或 `加一(2 * 3)` |
| `绝对值 -5` | `绝对值(-5)` |

## 验收

1. `打印 报时` 输出函数值，不自动调用
2. `打印 报时()` 输出 `十二点`
3. 不写 `依赖 数学库`，`打印 √16` 输出 `4`
4. `打印 正弦 30°` 仍需 `依赖 数学库`，但 `°` 本身不再报数学库缺失
5. `打印 加一 2 * 3` 报语法错误，消息含“并置调用”
6. `打印 (加一 2) * 3` 输出 `9`
7. `打印 加一(2 * 3)` 输出 `7`
8. 文法和关键字表只有一份来源
