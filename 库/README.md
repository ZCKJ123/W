# 库

## 文语言自写库

- `几何库.wen`：圆面积、圆周长
- `演算库.wen`：均方根、归一化、峰值、滑动平均、点积、距离
- `解析库.wen`：文语言自写全量词法器 + 表达式/语句 AST
- `自举库.wen`：文语言自写词法/语法/AST/代码生成；`编译源` 支持变量、分支、循环、函数调用/递归、返回 → x64 机器码
- `集合库.wen`：并集、交集、差集、子集、对称差、集合删除
- `自举运行时.wen`：自举链路（编译模式 + 求值器）共用的运行时。列表/字典/缓冲/文本原语都在这里，
  既是机器码侧的裸布局实现，也负责把宿主真值（真文本、真列表、真集合）接进来
- `自举求值.wen`：文语言自写求值器，`求值源` / `求值文件` / `运行文言` 三个入口，逃逸两套语义
- `自举库.wen` 与 `自举运行时.wen` 的分工：前者只产机器码，后者提供运行期原语

这份清单只覆盖最初的几个库，**不是全量**（目录里现在有 37 个 `.wen` 库 + 1 个 `.库`，
内置库看 `wen.exe --库`）。新增库时请顺手在这里补一行。

这些库不是 C++ 内置，直接由 `依赖 库名` 加载，`导出` 决定暴露哪些函数。

```wen
依赖 演算库
打印 均方根([3, 4])
```

## 内置库

`--库` 列出的仍是 C++ 编译进解释器的库。后续会把集合、统计、字符串等纯计算函数逐步迁到 `库/*.wen`，让核心变小、库层变大。
