# 库

## 文语言自写库

- `几何库.wen`：圆面积、圆周长
- `演算库.wen`：均方根、归一化、峰值、滑动平均、点积、距离
- `解析库.wen`：文语言自写全量词法器，输出 token 流
- `自举库.wen`：文语言自写表达式编译器，整数四则运算 → x64 机器码
- `集合库.wen`：并集、交集、差集、子集、对称差、集合删除

这些库不是 C++ 内置，直接由 `依赖 库名` 加载，`导出` 决定暴露哪些函数。

```wen
依赖 演算库
打印 均方根([3, 4])
```

## 内置库

`--库` 列出的仍是 C++ 编译进解释器的库。后续会把集合、统计、字符串等纯计算函数逐步迁到 `库/*.wen`，让核心变小、库层变大。
