# 文语言任务模板

每个模板改两个数字/路径就能用。

| 文件 | 用途 |
|---|---|
| 01读CSV求和.wen | 读 CSV，按第二列求和 |
| 02JSON取字段.wen | 读 JSON 字段 |
| 03复制文件.wen | 二进制复制 |
| 04哈希校验.wen | 计算 SHA256 |
| 05抓网页.wen | 抓取网页文本 |
| 06二进制读头.wen | 读 PE 头字段 |
| 07布局解析.wen | 紧凑布局读写 |
| 08批量改名.wen | 列出目录文件 |
| 09日志过滤.wen | 过滤含“错误”的行 |
| 10生成报告.wen | 写 CSV 报告 |

运行：`wen.exe 模板\01读CSV求和.wen`。
