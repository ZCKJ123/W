# 文言编程 · 零基础入门

> 只用 10 分钟，先跑起来，再学会看懂和修改。
> 不需要编译知识，不需要安装 Python / C++ / 编译器。

---

## 1. 这是什么

**文言**是一门用中文关键字写程序的小语言。

你写的文件长这样：

```wen
将 甲 变成 3
将 乙 变成 4
打印 "甲 + 乙 =", 甲 + 乙
```

保存成 `计算.脚本`，用 `wen.exe` 运行，就会输出：

```text
甲 + 乙 = 7
```

就这三个东西：

| 东西 | 作用 |
|---|---|
| `wen.exe` | 运行器，双击或命令行用它跑程序 |
| `xxx.脚本` | 你写的程序，用记事本 / VS Code 都能编辑 |
| `打印` | 把结果显示在屏幕上 |

## 2. 三步跑起来（Windows）

### 第一步：解压

把压缩包解压到**桌面**或 `D:\文言` 这种**没有中文空格、路径短**的地方。

解压后应该有：

```text
文言入门\
  wen.exe
  运行示例.bat
  教程.md
  示例\
    01_你好.脚本
    02_变量和计算.脚本
    ...
```

### 第二步：双击 `运行示例.bat`

它会自动运行 `示例` 文件夹里的所有程序，并停住等你看完，不会黑窗口一闪就没。

### 第三步：自己改一个

用记事本打开：

```text
示例\02_变量和计算.脚本
```

把 `3` 改成 `100`，保存，再双击 `运行示例.bat`，看结果变化。

> 改文件时如果记事本问“编码”，选 **UTF-8**。

## 3. 你只需要先记住 6 个词

### 3.1 `将 … 变成 …`：存一个值

```wen
将 名字 变成 "小明"
将 年龄 变成 18
将 分数 变成 95
```

可以理解成：**把右边的值，放进左边的名字里**。

### 3.2 `打印`：显示出来

```wen
打印 "你好"
打印 名字
打印 "年龄 =", 年龄
```

多个值用**英文逗号**隔开，输出时自动加空格。

### 3.3 `如果 … 则 … 结束`：做选择

```wen
如果 分数 >= 90 则
    打印 "优秀"
否则如果 分数 >= 60 则
    打印 "及格"
否则
    打印 "不及格"
结束
```

注意：

- `则` 后面换行
- 最后一定有 `结束`
- 可以有多个 `否则如果`
- `否则` 最多一个

### 3.4 `当 … 则 … 结束`：条件循环

```wen
将 甲 变成 1
当 甲 <= 5 则
    打印 甲
    将 甲 变成 甲 + 1
结束
```

输出 1 到 5。

> 循环里一定要让条件最终变假（这里是 `甲` 一直加 1），否则会死循环。

### 3.5 `对于 … 在 … 中 则 … 结束`：把列表走一遍

```wen
将 水果 变成 ["苹果", "香蕉", "橘子"]
对于 一个 在 水果 中 则
    打印 一个
结束
```

### 3.6 `函数 … 则 … 结束`：把一段操作起个名字

```wen
函数 加法 甲 乙 则
    返回 甲 + 乙
结束

打印 加法(2, 3)
```

函数用 `返回` 把结果交回去。没有 `返回` 就交回 0。

## 4. 三种最常用的数据

### 数字

```wen
将 甲 变成 3
将 乙 变成 3.14
```

### 文本（字符串）

```wen
将 名字 变成 "小明"
打印 "你好，" + 名字
```

文本用**英文双引号**包起来。

### 列表

```wen
将 分数 变成 [90, 85, 77]
打印 分数[0]        # 90，下标从 0 开始
打印 长度 分数       # 3
将 分数[1] 变成 88
追加(分数, 100)
```

### 字典

```wen
将 学生 变成 {"名字": "小明", "年龄": 18}
打印 学生["名字"]
将 学生["年龄"] 变成 19
```

## 5. 完整例子：99 乘法表

这是最能练手的小程序：**嵌套循环 + 乘法 + 打印**。

```wen
将 甲 变成 1
当 甲 <= 9 则
    将 乙 变成 1
    当 乙 <= 甲 则
        打印 甲, "×", 乙, "=", 甲 * 乙
        将 乙 变成 乙 + 1
    结束
    打印 ""
    将 甲 变成 甲 + 1
结束
```

运行后会输出：

```text
1×1=1
2×1=2 2×2=4
3×1=3 3×2=6 3×3=9
...
9×1=9 ... 9×9=81
```

先别追求一次写对。**改一个数字、跑一次、看结果**，这是最快的学习方式。

## 6. 新手最常踩的 8 个坑

### 坑 1：忘了 `结束`

```wen
如果 甲 > 0 则
    打印 "正数"
# 少了 结束
```

报错通常会指向后面某一行，不一定是真正缺 `结束` 的地方。

### 坑 2：用了中文标点

```wen
打印 “你好”      # 错：中文引号
打印 "你好"       # 对：英文引号
```

逗号、括号、引号都尽量用**英文半角**。

### 坑 3：`=` 和 `变成` 混了

```wen
将 甲 = 3       # 错
将 甲 变成 3     # 对
如果 甲 = 3 则   # 错
如果 甲 == 3 则  # 对（或写 如果 甲 等于 3 则）
```

### 坑 4：`打印` 多个值用了中文逗号

```wen
打印 甲，乙      # 错
打印 甲, 乙      # 对
```

### 坑 5：文件不是 UTF-8

中文变成乱码，或者第一行就报错。

用 VS Code 打开，右下角选 **UTF-8**，另存一次。

### 坑 6：路径有空格 / 中文

程序文件和 `wen.exe` 尽量放在短路径下，例如：

```text
D:\wen\
```

不要放在：

```text
C:\Users\张三\桌面\新建文件夹 (2)\...
```

### 坑 7：`长度 列 * 2` 不是你以为的意思

没有括号时，可能被理解成 `长度(列 * 2)`。

想表达“长度乘以 2”，写成：

```wen
(长度 列) * 2
```

### 坑 8：变量名和库函数重名

`值`、`键`、`长度`、`打印`、`文本` 这些名字，有些已经是库里的函数。

```wen
函数 阶乘 值 则
    将 下 变成 值 - 1     # 可能被理解成调用 值(-1)
结束
```

把参数改名为 `数`、`数字`、`数据` 这类名字，就不会歧义：

```wen
函数 阶乘 数 则
    将 下 变成 数 - 1
结束
```

### 坑 9：死循环

```wen
当 甲 < 10 则
    打印 甲
结束
```

`甲` 永远不变，条件永远成立。循环体里要有 `将 甲 变成 甲 + 1` 这样的推进。

## 7. 怎么看待报错

报错不用全懂，先找三个信息：

```text
第几行
原因
建议
```

例如：

```text
第 5 行：未定义变量「甲」
```

通常就是：**这个名字还没用 `将` 存过**，或者**打错字了**。

先看行号，再看那一行前后 3 行，80% 的问题都能自己解决。

## 8. 接下来学什么

按这个顺序，不要跳：

1. 把 `示例` 里 8 个程序全部跑一遍
2. 每个程序改一个数字 / 一句话，再跑
3. 自己写：输入两个数，输出和、差、积、商
4. 自己写：判断一个数是不是偶数
5. 自己写：求 1 到 100 的和
6. 自己写：打印 99 乘法表（不看示例）
7. 再去看仓库里的《使用教程.md》和《语法总表.md》

学到第 6 步，你已经能看懂大部分文言小程序了。

## 9. 一句话总结

```text
将 名字 变成 值
打印 值
如果 条件 则 … 结束
当 条件 则 … 结束
对于 项 在 列表 中 则 … 结束
函数 名 参数 则 … 返回 值 结束
```

**先跑，再改，再写。** 不要一上来读 1000 行文档。
