# 文言速查表（一页版）

## 存值 / 输出

```wen
将 甲 变成 3
将 名字 变成 "小明"
打印 "你好"
打印 "年龄 =", 18
```

## 判断

```wen
如果 分数 >= 90 则
    打印 "优秀"
否则如果 分数 >= 60 则
    打印 "及格"
否则
    打印 "不及格"
结束
```

## 循环

```wen
将 甲 变成 1
当 甲 <= 5 则
    打印 甲
    将 甲 变成 甲 + 1
结束

对于 项 在 [1, 2, 3] 中 则
    打印 项
结束
```

## 函数

```wen
函数 加法 甲 乙 则
    返回 甲 + 乙
结束

打印 加法(2, 3)
```

## 列表

```wen
将 列 变成 [10, 20, 30]
打印 列[0]
将 列[1] 变成 25
追加(列, 40)
打印 长度 列
```

## 字典

```wen
将 人 变成 {"名字": "小明", "年龄": 18}
打印 人["名字"]
将 人["年龄"] 变成 19
```
