## 构建与运行

```powershell
.\完整构建.bat   # 完整版：wen_full.exe
.\wen.exe 例子\你好.wen
.\wen.exe 工程\文工作台\工作台.wen   # 图形工作台
.\wen.exe 工程\时钟\时钟.wen         # 时间/秒针演示
.\wen.exe --签名
.\wen.exe --验证
.\wen.exe --库
.\发布检查.ps1   # 发货前检查
```

## 能做什么

- 中文关键字、少括号、块用 `则 … 结束`
- 数学/概率/物理/图形/函数库
- 文件/网络/网页/JSON/CSV
- 时间、路径、日志、哈希、Base64/URL 编码、正则
- SVG / OpenGL 4.6 / Vulkan 1.3 / WebGPU 导出
- 3D 渲染：立方体/球/OBJ；OpenGL 3D 走深度缓冲，Vulkan/WebGPU 暂投影
- 外派到 Python/JavaScript/JSON/Java
- 翻译到字节码/C++/汇编；字节码可执行
- 二进制缓冲、CPU 并行归约
- 内存缓存、压缩、牵引、跃迁、加速
