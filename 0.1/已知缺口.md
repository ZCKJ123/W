# 文语言 0.1 已知缺口

0.1 按“能用 + 缺口写清楚”收口，不按“没 bug”收。  
以下不是隐藏问题，是明确不在这版修的范围。

## 不修，写清楚

| 缺口 | 现状 | 影响 |
|---|---|---|
| 字节码覆盖窄 | 支持纯数值、`当`、列表、字典、索引、切片、列表/字典 `对于`、`中断/继续`、函数、递归、`√` | 嵌套函数/闭包仍不支持 |

## 数学计算

- `圆周率` 不再用 `acos(-1)`，改 Machin 公式 + BigInt 定点计算。
- `高精度圆周率([位数])` 默认 50 位，可到 10000 位。
- `平方根` 改牛顿迭代。
- `正弦`、`余弦`、`正切` 改核心泰勒展开，不再直接调 libm。
- `角度转弧度`、`弧度转角度` 用算出的圆周率。

## 0.1 必须修，已修

| 问题 | 修复 |
|---|---|
| 用户函数名撞内置名，外派/翻译报“内置函数没有映射” | 翻译前检查冲突，报“用户函数「X」与内置函数同名，无法区分；请改名” |
| 翻译/外派失败显示“解释器内部异常” | 增加“翻译错误”“外派错误”说明：源码或目标问题，不是解释器故障 |
| 圆周率只有双精度 | 新增 `高精度圆周率([位数])`，默认 50 位，可设 1..10000；`圆周率精度([位数])` 改默认 |
| `√`、`°` 依赖数学库 | 改成核心一元/后缀节点，不写依赖可用 |
| `圆周率`、`自然常数` 依赖数学库 | 改成核心常量，由 Machin/级数算出 |
| 零参自动调用 | 删除；`报时` 是值，`报时()` 才是调用 |
| 并置调用混二元运算符 | 语法层直接报“请用括号分组” |
| 文本插值 | 改成核心 `插值` AST；覆盖 `文本` 名字也不影响 `f"{x}"` |

对应用例：

- `测试/错误/08翻译撞名.wen`
- `测试/错误/09翻译说明.wen`
