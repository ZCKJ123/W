# 内存复用：48 台虚拟机共用一份镜像，实测 42.68 倍

把容量层接到“虚拟机内存”这个场景上——这是内存去重最真实的用途（KSM、VMware TPS 都是这个）。

## 实测

```text
48 台虚拟机：每台 1MB 系统镜像（完全相同）+ 16KB 私有页（改 1KB）

键数     49
逻辑     48.75 MB（48 台 × (1MB 镜像 + 16KB 私有页)）
物理     1169.6 KB
唯一块   2322 块
倍数     42.68 倍

换算：512GB 内存按这个复用率，能装 21.3 TB 的虚拟机内存

取回校验（第 48 台虚机私有页）
  原始 CE75436B…4F1025F7
  取回 CE75436B…4F1025F7
  PASS：私有页逐字节一致
```

## 为什么能到 42 倍

```text
镜像只有一份：48 台共享同一组分块，物理只占 1MB
私有页各自不同：每台只多出 1–2 个分块（约 1–2KB）
逻辑上每台都要算 1MB + 16KB
```

这就是“同构负载”的典型：云主机、容器、VDI、测试集群，OS 页高度重合。

## 这个 42 倍能直接翻译成“512GB 装多少”

```text
512GB × 42.68 ≈ 21.3 TB 的虚拟机内存
但前提是：这些虚拟机跑的是同一套镜像，私有数据只占很小一部分
```

换成普通工作负载（浏览器、编译、数据库），页重合度低：
内存压缩能到 1.5–3 倍，去重基本帮不上忙。

## 边界

```text
同一镜像的 N 台虚机      → 倍数 ≈ (镜像+私有)/新增 ≈ 镜像/私有 → 几十倍
各不相同的进程           → 约 1 倍
已压缩/加密数据          → 约 1 倍
私有页占比越大，倍数越低
```

## 复现

```powershell
.\wen.exe 工具\内存复用虚机.wen
```

## 和真实系统的对应

```text

Windows 内存压缩     单机不活跃页压缩，1.5–3 倍
本工具              分块级去重 + 差分链，逻辑上比页级更细
```
