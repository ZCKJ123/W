# 跨块邻域平滑：块边界上的格子也能算对

分块体做 3×3×3 平滑，最容易错的地方是**块边界**：邻居在隔壁块里，直接按块内地址读就会漏。
`分块平滑块` 的做法是先拼一张带 halo 的 34³ 缓冲，再逐格求均值。

## 实测（`工具/跨块平滑演示.wen`，64³ 体 = 8 个 32³ 块）

```text
对中心块做 3×3×3 平滑（带 halo）
  平滑一块耗时 4806 毫秒

边界取样校验：不符 0 个（共 8 个点）
  PASS：跨块邻域平滑正确
```

8 个测试点全在块边界/角上（`(0,0,0)`、`(0,0,31)`、`(31,31,31)`、`(0,16,16)`…），
每个都和「逐格读 27 个邻居再求均值」的独立结果一致。

## 做法

```text
1. 建 34³ 缓冲（块 32³ 四周各加 1 格 halo）
2. 填缓冲时直接 体读(体, 层起+l-1, 行起+r-1, 列起+c-1)
   —— 越界自动返回 0，隔壁块的邻居也读得到
3. 在缓冲里做 3×3×3 均值，写回 32³ 结果
```

关键就是第 2 步：**跨块读走的是同一套 (层,行,列) 地址**，不需要特殊分支。

## 性能

```text
一块 32³ = 32768 格 × 27 次邻域读 ≈ 88 万次 → 4.8 秒（解释执行）
整层 64³ 有 8 块 → 约 38 秒；256³ 有 512 块 → 太大，必须走编译或并行
```

## 边界

```text
正确性：已用边界 8 点交叉验证
性能：单块可用，整卷要分批/并行
内存：每块临时 34³ 缓冲（约 39KB），跑完即丢
```

## 复现

```powershell
.\wen.exe 工具\跨块平滑演示.wen
```
