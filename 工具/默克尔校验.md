# 默克尔校验 + 奇偶校验（SHA-256 版）

`工具/默克尔校验.wen`：读文件 → 4KB 分块 → SHA-256 叶哈希 → 默克尔根；
改一个字节就能定位到块；再用奇偶校验块把坏块恢复出来。

## 实测输出

```text
文件 31260 字节，切 8 块（4096 字节/块）
默克尔根 96B9DD12E6067456704F3D893496F0511281299AB8C2653AA079B8ABB4AF4148

改掉第 5000 字节之后：
  新根 9D39E419AADB5295A250B5785BA442E5B70EA074AA2909D5B92E15AEC23218E4
  根已变，定位到块 1

奇偶校验：取 4 块做 1 个校验块（开销 25%）
  校验块哈希 CBAE3AC6…3F61F
  第 2 块被破坏，哈希 C5A3C452…B9CF67
  用校验块 + 其余 3 块恢复，哈希 1D182126…C9016
  恢复成功，与原始块一致
```

## 根哈希已独立复核

用 PowerShell 按同样规则（4KB 分块、SHA-256、奇数节点上提、
内部节点 = SHA256(左十六进制 + "|" + 右十六进制)）重算一遍：

```text
独立复核根 = 96B9DD12E6067456704F3D893496F0511281299AB8C2653AA079B8ABB4AF4148
```

与文语言实现的结果一致。

## 原理

```text
默克尔树  叶子 = 每块 SHA-256；逐层两两合并到根
          改一个字节 → 叶子变 → 根必变 → 逐块比对定位到块 1
          下载时只重下这一块，不用重下 49 TB
奇偶校验  校验块 = 所有数据块逐字节异或
          坏一块：恢复 = 校验块 ⊕ 其余好块（异或自反）
```

## 条带参数

```text
4 + 1     开销 25%，扛 1 块坏（演示用）
32 + 2    开销 6.25%，扛 2 块
64 + 3    开销 4.69%，扛 3 块（49TB 装 52TB 需要，见 工具/条带预算.md）
128 + 6   开销 4.69%，扛 6 块
```

奇偶校验是 RS 的退化情形，真实系统用 `库/纠删码.wen` 那套系统化范德蒙。

## 依赖与限制

```text
依赖 哈希库（缓冲SHA256 / SHA256），宿主原生实现，31KB 0 毫秒
独立求值器没有这个内建；要在求值器里跑，改用 库/散列库.wen 的纯文语言 SHA-256
（正确但慢：31KB 约 19.6 秒）
校验只负责“发现”，恢复靠奇偶/纠删码；“绝对静态”还靠写时复制 + 内容寻址 + 只追加 + 定期巡检
```

## 语言坑（写这类工具会踩）

```text
文语言里，函数内给“不在参数表里的名字”赋值会落到全局。
第一版用 序 / 起 / 止 当顶层循环变量，被 片段() 内部的 序 覆盖，
结果只切出 1 块、根哈希没变。现在顶层变量统一改成 块序 / 切起 / 切止。
可以用 工具/作用域检查.ps1 扫这类问题。
```

## 复现

```powershell
.\wen.exe 工具\默克尔校验.wen
```
