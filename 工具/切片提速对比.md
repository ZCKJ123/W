# 切片提速：逐格读 3608ms → 按块拷贝 17ms，212 倍

上一版取一层截面对大体积要 48 秒，问题就出在“逐格读”。
`库/分块体.wen` 新增 `分块切片缓冲`，按块整块拷贝，`库/三维.wen` 新增 `三维切片缓冲`。

## 实测（`工具/切片提速对比.wen`，256³ 体取第 128 层）

```text
256³ 体：总格 16777216，物理 256.1 KB，块数 8
逐格读（转二维列表）：3608 毫秒，中心格 255
按块拷贝（连续缓冲）：17 毫秒，中心格 255

加速比约 212.2 倍
切片指纹（缓冲版） A0B695CA…E5FEF66E
```

## 慢在哪

```text
逐格读：每格都要 ①算块键字符串 ②查字典 ③算块内地址 ④读缓冲
        65536 格 × 4 步，其中两步是字符串拼接和哈希查找 → 3.6 秒

按块拷贝：只做 64 次块查找，然后 64 × 32×32 次纯缓冲读写
        没有字符串、没有字典 → 17 毫秒
```

## 接口变化

```wen
三维切片(卷, 层)        返回二维列表（方便，但大体积慢）
三维切片缓冲(卷, 层)     返回连续缓冲（快，推荐给大体积）
分块切片缓冲(体, 层)     底层的按块实现
```

## 结论

```text
同样的数据、同样的结果（中心格、指纹都对），只改“怎么搬”：
把逐格访问换成按块访问 → 两个数量级
```

这也是所有体渲染/体数据系统的常识：**按块（tile）访问，别按元素访问**。

## 复现

```powershell
.\wen.exe 工具\切片提速对比.wen
```
