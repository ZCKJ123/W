# 三维统一入口：同一份调用代码，底层自动选稠密或分块

`库/三维.wen` 把前面两层包成一个接口：

```wen
将 卷 变成 新建三维(256, 256, 256)   # ≤ 262144 格自动稠密，否则自动分块
三维写(卷, 层, 行, 列, 255)
三维读(卷, 层, 行, 列)
三维统计(卷)     # 型 / 总格 / 物理字节 / 倍数
三维指纹(卷)
三维切片(卷, 层)
三维平滑(卷)     # 目前只支持稠密体
```

## 实测（`工具/三维统一演示.wen`）

```text
小卷 32³：稠密  总格 32768  物理 32.0 KB  倍数 1.0
  指纹 A6DDADEFA71A432944674759DE794D3A50CA0CF5CD9B4E5C6D903D4B852D8872

大卷 256³：分块  总格 16777216  物理 256.1 KB  倍数 64.0
  块数 8  指纹 730055F589544C95181CDDDF99EF646F063CACBFA9983BD84F31517AE89A90E4

同一份读代码：
  小卷 中心 255
  大卷 中心 255
  大卷 球外 0

小卷平滑后中心 255
大卷第 128 层第 128 行：列 120→255 … 列 136→255
```

## 几个要点

```text
同一份 三维写/三维读 代码，小卷走稠密、大卷走分块，调用方不用改
小卷指纹和 工具/体数据演示.wen 的结果完全一致 → 确定性可复现
大卷 16.7M 格只占 256KB → 稀疏比 64 倍
```

## 性能

```text
本次演示总耗时约 48 秒，大头是「取一层截面」——65536 次逐格读，
每次都要算块键、查字典。真要用得改成按块整块拷贝，能快两个数量级。
```

## 边界

```text
稠密体   小体积、实心、需要邻域平滑 → 用这个
分块体   大体积、稀疏（球壳/点云/SDF） → 用这个
平滑     目前只支持稠密体；分块体跨块邻域（halo）还没做
```

## 复现

```powershell
.\wen.exe 工具\三维统一演示.wen
```
