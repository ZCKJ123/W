# 实心块压缩：整块一个值，8 字节顶 32KB

分块体里每个 32³ 小块现在有两种存法：

```text
常量块 {满:1, 值:v}     整块一个值，占 8 字节
缓冲块 {满:0, 缓:buf}   有变化，占 32KB
```

写的时候自动判断：整块填同一个值就走常量，一旦写入不同值就展开成缓冲。

## 实测（`工具/实心块压缩演示.wen`）

```text
256³ 体，中间 64³ 实心方块（值 255），其余为 0
  逻辑格数   16777216
  分配块数   8
  常量块     8 个（每个 8 字节）
  缓冲块     0 个（每个 32KB）
  物理字节   192 字节
  逻辑/物理  87381.3 倍

校验：内部 255，边界内 255，边界外 0  →  PASS
```

对照：

```text
同样的位置写 256 个不同值
  常量块 0 个，缓冲块 1 个，物理 32784 字节
  —— 一旦块里有不同值，就得展开成 32KB
```

## 这条优化抓住的是“大片同值”

```text
背景/空白区域    全是 0 → 常量块
实心区域         全是一个值 → 常量块
渐变/噪声区域    走缓冲块，32KB
球壳/表面       只有表面块有变化
```

真实体数据（CT、SDF、点云、医学影像）大部分区域是背景或实心，
所以常量块命中率很高——这就是工业界 3D 纹理里的 constant tile 压缩。

## 代价

```text
读：常量块直接返回值，比读缓冲还快
写：整块同值不分配；变了一个格子就展开 32KB（一次性）
统计：常量块按 8 字节计，缓冲块按 32KB 计
```

## 边界

```text
大片同值 → 上千倍（本例 8.7 万倍，因为逻辑体积大、物理只有 192 字节）
有噪声/渐变 → 退化成 32KB 一块，倍数回到稀疏比
```

## 复现

```powershell
.\wen.exe 工具\实心块压缩演示.wen
```
