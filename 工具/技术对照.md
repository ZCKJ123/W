# 这套技术，微软有吗？——逐层对照

先把问题拆成三层：**芯片级叠层**、**系统级容错**、**研究级三维存储**。
微软在其中一层有、一层很强、一层是研究项目；叠层颗粒本身不是微软做的。

## 一、芯片级三维叠层：不是微软，是存储厂

```text
3D NAND：三星、SK 海力士、美光、铠侠/闪迪、长江存储
  2026 年量产档：铠侠+闪迪 332 层，三星 400 层在路线图上
  [Kioxia/SanDisk 332 层](https://tech.yahoo.com/computing/articles/kioxia-sandisk-sample-worlds-densest-111000368.html)

HBM：DRAM 裸片 TSV 堆叠，12 层、单堆栈 36GB
  [SK 海力士 12 层 HBM3E 量产](https://news.skhynix.com/cn/sk-hynix-begins-volume-production-of-the-world-first-12-layer-hbm3e/)
  [三星 36GB HBM3E 12H](https://semiconductor.samsung.com/kr/news-events/news/samsung-develops-industry-first-36gb-hbm3e-12h-dram/)
```

这就是“512GB 变 1024GB”的工业原型：底面不变，往上叠层。
微软不造这个，Azure 是买家。

## 二、系统级容错与校验：微软很强，而且早就有

```text
纠删码（对应本仓库 库/纠删码.wen）
  Azure Storage 的 LRC（Local Reconstruction Codes），USENIX ATC 2012 最佳论文，
  用 1.3–1.6 倍开销替代 3 副本
  [Erasure Coding in Windows Azure Storage](https://learn.microsoft.com/nb-no/archive/blogs/windowsazurestorage/usenix-best-paper-award-erasure-coding-in-windows-azure-storage)

完整性校验（对应 工具/默克尔校验.wen）
  ReFS 的 integrity streams：每文件/每流 SHA-256 校验、巡检、坏块修复
  [ReFS overview](https://raw.githubusercontent.com/MicrosoftDocs/windowsserverdocs/1ef166b70da4b246552f60fc15139ffae53df091/WindowsServerDocs/storage/refs/refs-overview.md)

分层与冗余（对应 工具/三维块级存储.wen 的备用池）
  Storage Spaces：镜像 / 奇偶 / 分层；Windows Server 还有去重
```

所以“校验、纠删码、写时复制、巡检修复”这些不是我们发明的，
微软 2012 年就在 Azure 上跑了。

## 三、研究级三维存储：微软研究院的 Project Silica

```text
石英玻璃里用飞秒激光写三维体素，显微镜读回，目标是千年归档
  [Microsoft 玻璃存储（The Register）](https://assets.theregister.com/2026/02/19/microsoft_glass_storage/)
  [Project Silica 报道](https://tech.yahoo.com/computing/articles/project-silica-promises-store-data-160500204.html#1)
```

这是微软在“三维体存储”上最接近我们讨论的东西：
不是硅片叠层，而是同一块介质里用深度维度存数据。

## 四、那我们这套到底是什么

```text
不是新物理：叠层、纠删码、默克尔、写时复制、巡检，工业界都有
是模型与实现：
  三杠杆容量模型（层数 × 位数 × 纠错）     工具/三维多值存储.wen
  面密度与每 bit 成本的量化                 工具/扩容质证.wen
  GF(256) 真编解码                         库/纠删码.wen
  SHA-256 默克尔 + 定位 + 奇偶恢复          工具/默克尔校验.wen
  坏块全局备用池的可靠性差                  工具/三维块级存储.wen
  49TB/52TB 的真实条带预算                 工具/条带预算.wen
```

## 五、面对质疑，正确的说法

```text
别说：我们发明了三维叠层扩容
要说：三维叠层是 3D NAND/HBM 的既有路线（铠侠 332 层、海力士 12 层 HBM），
      我们做的是把“层数 × 位数 × 纠错”的容量与代价量化成可跑模型，
      并在文语言里实现了纠删码、默克尔校验、坏块池这三块，
      能复现、能算账、能验证加层不搬迁。
```

这样既不吹，也站得住：物理原理是行业的，量化模型和可跑实现是我们这边的。
