# 三维多值存储模型（C 路线：层数 × 位数）

回答一个问题：底面 512GB，走“叠层 + 每格多值”这条路，最后**拿到手的容量**是多少。

实现：`工具/三维多值存储.wen`（可复现，固定随机种子）

## 公式

```text
理论容量 = 底面格数 × 每格位数 × 层数 × (1 - 纠错开销) × (可用层 / 层数)
可用层   = 层数 - 备用层
备用层   = 期望坏层 + 3σ
```

三个参数各自有代价：

```text
层数        容量 ×层数，代价是工艺层数、体积、良率
每格位数    容量 ×位数，代价是读出裕度变小、误码上升、变慢
纠错开销    由误码率决定，误码越高，能拿来存用户数据的比例越低
```

## 误码怎么来的

蒙特卡洛：每格写入一个电平中心 `(级 + 0.5) / 级数`，读回时加高斯噪声
（12 个均匀分布求和 − 6），再按阈值判级，和写入级做汉明距离，得到位错率。
每级 1500 个样本，种子固定，结果可复现。

纠错开销用信息论下限再乘工程系数：

```text
开销 = 1.4 × H(p)，下限 2%，上限 50%
H(p) = -p·log2(p) - (1-p)·log2(1-p)
```

## 实测：底面 512GB、坏层率 0.4%

噪声 2% 满量程：

```text
位数  位错率    纠错开销   32层      64层      128层     232层
1     0.000%    2.0%      15.4 TB   31.7 TB   64.0 TB   116.7 TB
2     0.000%    2.0%      30.7 TB   63.5 TB   128.0 TB  233.5 TB
3     0.069%    2.0%      46.1 TB   95.2 TB   192.0 TB  350.2 TB
4     4.444%   36.7%      39.7 TB   82.0 TB   165.3 TB  301.5 TB
```

噪声 3% 满量程：

```text
位数  位错率    纠错开销   32层      64层      128层     232层
1     0.000%    2.0%      15.4 TB   31.7 TB   64.0 TB   116.7 TB
2     0.000%    2.0%      30.7 TB   63.5 TB   128.0 TB  233.5 TB
3     1.478%   15.5%      39.7 TB   82.1 TB   165.5 TB  301.8 TB
4    11.217%   50.0%      31.3 TB   64.8 TB   130.6 TB   （噪声吃掉一半以上）
```

## 结论

```text
1. 层数是最干净的杠杆：噪声不变时，层数直接乘容量，纠错开销几乎不动
2. 位数是带利息的杠杆：每加一位，读出裕度减半，误码按数量级涨，
   纠错开销把多出来的容量吃掉一部分
3. 所以“层数 × 位数”不能同时拉满：
   噪声 2% 时，232 层 QLC 反而输给 232 层 TLC（301.5 vs 350.2 TB）
   噪声 3% 时，QLC 的有效容量掉到 130.6 TB，TLC 才是对的
4. 现实里先上 TLC、把层数堆高，等读出精度和纠错码变强再谈 QLC——
   这个模型能直接看出拐点在哪
```
