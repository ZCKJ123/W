# 容量层：语言自带的去重 / 快照链 / 校验

不是三个演示脚本，是**一个库**：任何文语言程序写一行 `依赖 容量层` 就能用。

## 用法

```wen
依赖 容量层

将 层 变成 新建容量层()
存值(层, "v0", 第一版数据)
存值(层, "v1", 改过的数据)      # 自动和上一版做差分
将 回 变成 取值(层, "v1")
打印 容量报告(层)
打印 容量指纹(层)
```

## 实测（`工具/容量层演示.wen`）

```text
容量层：存了 128 个版本，每版 65536 字节，每版改 64 字节

键数     128
逻辑     8.00 MB
物理     247.6 KB
唯一块   301 块
倍数     33.09 倍

取回校验（最后一版）
  原始 948608F8…DA4A95
  取回 948608F8…DA4A95
  PASS：取回逐字节一致

整层指纹 3240DC1B…3B201FFF
```

## 内部做了什么

```text
切块      内容定义分块（256–1024 字节），切点由内容决定
收块      SHA-256 指纹，相同块只存一份
差分      新旧块号列表求公共前缀/后缀，只存中间变化的块号（快照链）
取值      沿链回溯，拼出完整块号列表再还原
报告      逻辑字节 / 物理占用 / 倍数
指纹      每个键的 SHA-256 拼成串再哈希 → 键级默克尔根
```

## 为什么这里是 33 倍，而不是 57 倍

```text
这个演示：每版 64KB 改 64 字节 → 每版新增约 1.3KB 分块 → 上限约 50 倍
   实际 128 版：逻辑 8MB / 物理 247.6KB = 33 倍（版本越多越接近上限）

三维卷/文件去重那两个：每快照只改总量 0.006% → 57 倍
```

倍数 = 每版字节 ÷ 每版新增字节，跟库本身无关，跟**改动密度**直接相关。

## 边界（同一个库，换参数就能看到）

```text
每版改 64 字节    → 33 倍（版本更多还能到 45 倍上下）
每版改 512 字节   → 26 倍
整版全改          → 接近 1 倍
随机/已压缩数据   → 约 1 倍
```

## 复现

```powershell
.\wen.exe 工具\容量层演示.wen
```

## 为什么这是“语言的事”

```text
没有 ABI、没有 C 运行时、没有外部依赖
去重、差分、校验全部在文语言里，能被别的文语言程序直接 依赖
改一行参数就能换策略，不需要重编 C 代码
```
