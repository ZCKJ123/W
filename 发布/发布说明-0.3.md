# 文语言 0.3.0-snapshot 发布说明

从 0.2 到 0.3，重点是把「三维计算」变成语言的一等能力，并且把速度拉到可用的量级。

## 一、性能（200³ = 800 万格实测）

| 操作 | 0.2 | 0.3 | 提升 |
|---|---|---|---|
| `体按公式`（脚本函数） | 53.6 s | 198 ms | **271×** |
| `体按公式`（公式字典） | 1.27 s | 41 ms | **31×** |
| `体等值面` | 1.478 s | 59 ms | **25×** |
| `体表面积` | 1.447 s | 63 ms | **23×** |
| `体惯性` | 256 ms | 28 ms | **9×** |
| `体距离场` | 496 ms | 352 ms | 1.4× |
| 单次函数调用 | 7.0 µs | 0.6 µs | **12×** |

做法（都是自己管理，不借通用容器）：

1. `返回` 不再抛异常，改成标志位逐层传递——函数调用从 7 µs 降到 0.85 µs；
2. 函数帧用「小数组」存参数和局部，不再每参数一次哈希表插入；
3. 调用点用解析期分好的 `SymId` 查函数，不再每次对中文名做字符串哈希；
4. 公式字典**先编译成节点树**再逐格求值，不再每格查 map、建数组；
5. 纯表达式函数（只含数字/参数/四则/比较/且或）**编译成栈式字节码**，逐格求值不进解释器——约 25 ns 一格；
6. Surface Nets（`体等值面` / `体表面积`）与 `体惯性`、`体距离场` 的热循环改成直接按指针读，去掉逐格边界检查。

## 二、三维计算

- 新增 `库/三维计算.wen`：造球/造盒/造环/造柱、并/交/差、平移/缩放、测量/报告、网格/导出
- 新增内建 `体平移`
- 惯量改为「体素按实心小立方」计算：立方体对解析式 **误差 0.000000000**
- `体距离场` 换成精确欧氏距离变换（Felzenszwalb 抛物线包络），负里正外

## 三、公式系统

- `库/公式库.wen`：球/盒/环/柱/面/波/高斯 七个模板，可当字典（原生求值）或脚本函数
- `库/公式代数.wen`：并/交/差/平移/缩放/壳，可无限套
- `体按公式` 支持 `(体, 公式, 里面值, 外面值)` 的 SDF 填充；`公式场` 用公式直接造 SDF 场

## 四、求解库

`库/求解库.wen`：子集和、0-1 背包、3-SAT（DPLL）、验证、数独、N 皇后。

实测：20 个随机 3-SAT 实例 20/20 通过（有解验证、无解暴力枚举确认）；
数独解出经典题；N 皇后 n=1..8 = `[1, 0, 0, 2, 10, 4, 40, 92]`（A000170）。

## 五、语言修正

- 函数里给「当前绑定是函数」的名字赋值会退化成局部变量，不再改全局、不再跨递归串值
- 中文代码清理：`库/工具/测试` 里所有英文标识符改为中文（`l/r/c` → 层坐标/行坐标/列坐标 等）
