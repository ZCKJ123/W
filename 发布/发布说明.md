# 文语言 0.2.0-snapshot 发布说明

## 独立求值器（新增）

`文言求值器.zip` 是自举编译器生成的 Windows x64 独立 PE：

- 不依赖 C/C++ 运行时
- 内置字符串 / 列表 / 字典 / 闭包 / 浮点 / 异常
- 已通过 `测试/用例` 的 01–08 全部用例
- 另通过 09函数库、65多行调用、100/101/103/104/107/108/110/137/138/147/97 等纯语言用例，合计 21 个
- 内置 映射/过滤/折叠/任意/全部/找到/计数/排序依据/去重/展平/最大/最小/平方根/查找字节
- 出错不闪退：未捕获的 `抛出` 写「运行时错误：原因」，退出码 1；表达式错误以错误对象返回
- 全量 148 个用例扫描：0 崩溃
- 用法：把 `.脚本` 拖到 `运行脚本.bat` 上

## 包内容

- `wen.exe`：免安装解释器，Windows 10/11 x64
- `例子/`：可直接运行的示例
- `库/`：标准库源码
- `模板/`：10 个任务模板，改路径/数字即可用
- `神经网络库`：神经层/神经链/前向/训练
- `网络库`：网络路径、防火墙规则、抓取拦截
- `README.md`、`使用教程.md`、`使用规范.md`、`更新目录.md`
- `版本验证报告.md`

## 验证

```powershell
.\wen.exe --验证
.\wen.exe --验证插件 插件\wen-check
```

- 官方签名、内嵌标记、版本号三者一致才视为可运行
- 非官方且版本不匹配的二进制拒绝运行

## 安全与限制

```powershell
.\wen.exe --限制 "时间=30秒,内存=512MB" 脚本.wen
```

- 递归超过 1000 层报「递归过深」，不会栈溢出闪退
- 写文件先写临时文件，成功后原子替换
- 时间/内存超限直接终止，退出码 124/125
